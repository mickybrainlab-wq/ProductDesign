This is actually a fundamental product strategy question.

Most people think there are only two ways:

1. Improve an existing product.
2. Create an alternative.

But almost every successful company is built using one of a small number of innovation patterns.

---

# The Product Opportunity Map

Think of every product as trying to solve a human problem.

There are many ways to create value.

---

# 1. Better Version (Improve)

Same problem.
Better solution.

Examples

* Google → better search
* Linear → better Jira
* Notion → better documents
* Figma → better design collaboration

Signal

> "People already use something but complain."

Questions

* What's slow?
* What's ugly?
* What's difficult?
* What's expensive?
* What's unreliable?

---

# 2. Alternative

Same problem.

Different philosophy.

Examples

Uber ↔ Taxi

DuckDuckGo ↔ Google

Signal ↔ WhatsApp

Linux ↔ Windows

Examples of differences

* Privacy
* Simplicity
* Speed
* Offline
* AI-first
* Open source

Signal

> "Some users want different values."

# A Universal Framework

Every product opportunity can usually be traced back to one of five root strategies:

| Root Strategy | Core Question                                    | Example                             |
| ------------- | ------------------------------------------------ | ----------------------------------- |
| Improve       | How can we make it better?                       | Better camera, faster IDE           |
| Simplify      | How can we remove friction?                      | Canva, Stripe                       |
| Transform     | How can new technology change the solution?      | AI coding assistants                |
| Connect       | How can we link people, businesses, or systems?  | Uber, Airbnb                        |
| Invent        | What important problem has no good solution yet? | First smartphone, first web browser |

## The mindset behind product creation

When analyzing any market, ask these questions in order:

1. What job is the customer trying to accomplish?
2. How do they solve it today?
3. What frustrates them?
4. What workarounds have they invented?
5. Which of the 25 opportunity patterns applies?
6. Can technology now make a dramatically better solution possible?

If you repeatedly evaluate markets through these lenses, you'll start seeing product opportunities almost everywhere—not just as "better versions," but as changes in experience, economics, technology, distribution, audience, and business model.
